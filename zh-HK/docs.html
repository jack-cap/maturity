匯出你的 Maturity 資料

結構描述 v1 · 本機 JSON 和 CSV 匯出

一切由你掌控。只有在你提出要求時，Maturity 才會建立匯出檔案。 應用程式會把完成的檔案交給系統儲存面板或分享表單；不會上載檔案、選擇收件者， 亦不會把檔案傳送給開發者。

1. 建立匯出檔案

在 Maturity 中開啟設定 → 資料 → 匯出投資組合…。 選擇格式及私隱模式，查看應用程式顯示的說明，然後按下匯出。

在 Mac 上，請從系統儲存面板選擇目的地。在 iPhone 及 iPad 上， 請從系統分享表單選擇目的地或收件者。你選擇其他應用程式、服務或人士後， Maturity 無法控制之後的處理方式。

2. 選擇私隱模式

  • 已隱去敏感資料是預設值。金融機構及帳戶名稱會改為該次匯出專用的別名，並排除使用者輸入的自由文字。
  • 財務分析會以別名取代金融機構名稱，並排除參考資料、附註及備忘錄；帳戶名稱則會保留。
  • 完成會包括金融機構及帳戶名稱、參考資料、附註及交易備忘錄。

財務分析及已隱去敏感資料匯出檔案都經過假名化，而非匿名化。 每種模式都會保留準確呈現投資組合所需的金額、利率、日期、貨幣、狀態及關聯識別碼。 這些欄位可能讓他人將匯出檔案與其他資料互相連結。分享前請檢查實際產生的檔案； 除非確實需要可讀標籤，否則請優先使用已隱去敏感資料模式。

3. JSON 快照

JSON 選項會建立具版本資料、可由機器讀取的快照。其中包括投資組合記錄， 以及預先計算的摘要、現金流、到期期間、流動性資料列、待處理項目及匯出來源資料。 數值會按貨幣分開保存；匯出檔案不會為不同貨幣虛構合併總額。

檔案中的結構描述資料可讓相容軟件辨識格式。即使選擇已隱去敏感資料模式， 亦應將完整 JSON 物件視為敏感財務資料。

4. CSV 資料套件

CSV 選項會建立副檔名為 .maturitycsv 的文件套件，其中包括 manifest.json 檔案及多個可互相聯結的 CSV 表格。 這些表格會將相關記錄分開保存，而不是把整個投資組合壓平成一份意義不明的試算表。

在 Mac 上，你可以在 Finder 中使用顯示套件內容檢查套件。 試算表應用程式可能會自行格式化日期、識別碼、利率或大數值， 因此重要資料請與 Maturity 及金融機構記錄核對。

5. 安全分享匯出檔案

Maturity 不會自動傳輸匯出檔案。如果你把檔案交給雲端儲存空間、AI 助理、分析軟件、 財務顧問或其他人士，該收件者就會取得檔案，並可能按其自身條款傳輸、處理、保留或記錄內容。 這類由使用者主動進行的分享不會讓 Maturity 的開發者取得匯出檔案。

  • 除非收件者確實需要可讀的名稱或附註，否則請使用已隱去敏感資料模式。
  • 分享前，請開啟並檢查完成的檔案。
  • 只傳送給你信任的收件者及服務。
  • 請使用目的地所提供的控制項來儲存及刪除匯出副本。
  • 請勿在公開的 GitHub issue 或其他公開支援渠道張貼匯出檔案。

如需了解保留欄位、本機匯出處理方式及第三方目的地的完整說明， 請參閱私隱政策（英文）。

6. 匯出不會執行的事項

  • 不會連接銀行、不會向金融機構驗證記錄，亦不會轉移資金。
  • 不會自行上載，亦不會公開 Maturity 的即時 SwiftData 儲存區或私人 iCloud 容器。
  • 不會令財務分析或已隱去敏感資料資料成為匿名資料。
  • 不會令計算結果的權威性高於銀行月結單或報價。

非財務建議

Maturity 是一款記錄及計算工具，不提供財務、投資或稅務建議，亦不推薦產品或金融機構。 匯出數字取決於使用者提供的記錄；仍應以銀行月結單及報價為準。 任何重大事項請向你的金融機構或持牌顧問確認。
