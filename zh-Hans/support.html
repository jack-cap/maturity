支持

适用于 iPhone、iPad 和 Mac 的 Maturity。

联系我们：请在 github.com/jack-cap/maturity/issues 提交 issue。欢迎报告错误、咨询计算问题或提出功能建议。GitHub 会收到你提交的内容及你的 GitHub 身份，而且 issue 可能公开显示。请勿发布财务记录或其他敏感信息。请注明所用设备和 操作系统版本；如咨询计算问题，请提供足以重现结果且不含敏感信息的代表性条款。

开始使用

  1. 设置期初余额。请输入你现在实际可以使用的现金，也就是你用于存入定期存款的账户所显示的余额。不要加上你已经持有的定期存款本金。
  2. 添加已经持有的定期存款。请按每笔存款的真实起始日期录入，即使那是几个月前。将每笔存款的资金来源设为“开始记录前已开立”，这样就不会为本金记录现金变动，因为银行早在这份账本建立前就已扣除那笔资金。
  3. 检查摘要。摘要首先显示追踪持仓。它正好等于已记录的自由现金（显示为当前可用）加上未结束定期存款的本金，不包括应计利息以及预计或未来利息。当前可用资金应已与你的银行余额一致；如果不一致，请使用核对现金记录差额。

最值得正确设置的一点。当前可用资金是交易历史的总和。如果你将今天的银行余额 作为期初金额输入，又让上周开立的一笔定期存款扣除本金，同一笔钱就会被扣除两次——银行扣一次， 应用再扣一次——最终会少掉这笔本金。每笔定期存款的资金来源设置正是为了避免这种情况。

常见问题

Maturity 如何帮助我管理滚动定期存款持仓组合？

先查看当前可用，了解现在可以存入多少资金，然后将到期阶梯切换为月。 它会显示未来十二个月中每个月已确定将返还的本金和利息，包括没有返还资金的月份。这些数字合在一起， 能让你看到今天有多少资金可用、之后预计返还什么，以及到期安排中有哪些空档。

这些信息可以帮助你规划让到期日分散在连续月份，或增加较短期和较长期存款的比重。后一种布局有时称为 杠铃策略，但真正有用的信息只是每笔资金何时重新可用。如果资金要到以后某个月才使用，也不必一直记为 闲置现金：你可以将它存入期限较短的定期存款并照常记录，这样该存款到期时就会显示在资金重新可用的月份。

Maturity 只报告你记录的金额和日期；它不会建议存入多少、选择多长期限、采用什么利率或购买哪种产品。 请根据每月空档和返还本金自行决定如何存入资金，然后添加每笔定期存款以保持计划最新。

如何添加我已经持有的定期存款？

按正常方式录入每笔存款并使用真实起始日期，再将资金来源设为“开始记录前已开立”。 这样会记录定期存款，但不会记录现金变动，因为本金在账本建立前就已离开账户。该存款仍会显示在持仓中、 仍会计入到期阶梯，并会在到期时把资金计入现金。

如果你更喜欢，也可以采用另一种同样可行的方法：将期初余额设为现金加上所持每笔定期存款的本金， 然后让每笔存款像往常一样从当前可用资金中出资。最终计算结果相同，只是你必须记住对每笔存款都遵循这条规则， 任何一次疏漏都会使余额少一笔。

为什么当前可用资金低于银行显示的余额？

几乎总是因为你在开始追踪前开立的某笔定期存款被设为从当前可用资金出资。应用扣除了本金， 但银行早已扣过这笔钱，因此同一笔资金被扣除了两次。

打开该定期存款，将资金来源改为“开始记录前已开立”，然后保存。相应现金变动会被移除， 当前可用资金将增加该笔本金。如果之后数字仍不一致，请使用核对现金记录剩余差额。

现金账户有什么作用？

存放在一家金融机构的现金无法直接用于在另一家机构开立定期存款——资金必须先转过去，而这可能需要几天。 因此，“我今天可以存入多少”只能按账户回答。账户也让核对过程符合现实：你会逐一核对每家银行的余额， 而不是核对一个合并数字。

在摘要中打开当前可用，即可查看账户和银行明细。现金存放位置会将账户归入 可折叠的银行标题下。一两家银行时默认展开；银行列表较长时默认折叠。每个标题会显示账户数量；如果所有账户 使用同一种货币，还会以该原始货币显示可安全相加的小计。若一家银行包含多种货币，则显示货币代码，而不会把 不同货币的金额相加。

在应用真正有用之前，我需要完成哪些设置？

需要完成四项；在完成前，摘要会以清单形式显示它们：

1. 你的货币。所有数据均按货币计价，绝不会把不同货币的总额混在一起， 因此这里决定新记录默认使用哪种货币。你可以直接在清单中选择；如果持有多种货币的定期存款， 可在设置中添加更多货币。

2. 你的银行账户。现金存放的每个位置都应建立一个账户，因为一个银行账户中的现金 必须先转移，才能用于另一家银行的定期存款。在每个账户上记录银行，应用才能在各处将同一家银行的账户归为一组。

3. 每个账户中的金额。为每个账户设置期初余额，这是衡量当前可用资金的起点。 每个账户都可以设置，不仅限于第一个账户。

4. 你已经持有的定期存款。此项可选；但如果你已经持有尚未到期的定期存款， 添加时请将资金来源设为开始记录前已开立，以免对追踪开始前已转出的资金重复扣减现金。

全新安装时，这些项目会作为引导流程逐阶段显示，而且会一直保持打开，直到你主动离开——因此不会在你录入 已持有的定期存款途中消失。之后，摘要中的单行提醒会指出下一项未完成内容并重新打开流程。你可以在那里关闭提醒， 也可以从设置中再次显示。

每个阶段都根据你的数据判断，而不是读取某个已保存的标记，因此不会在实际未完成时声称已完成，也不会无故提醒。 例如，余额阶段要求你建立的每一个账户都有期初余额，而不仅是第一个；在第二台设备上，如果完整持仓组合已经同步到达， 应用也不会重复催促。只有货币和一个账户是必需项；对于从零开始、尚无定期存款的用户，存款本来就是可选项。

Maturity 已经选好应用默认值，你可以在设置中按各产品情况更改。iCloud 无需配置，也不需要手动输入汇率。 如果启用显示参考等值，应用会按下文所述获取公开参考汇率。

如何开启到期提醒？

打开设置，在“通知”下开启到期提醒。启用时，应用会请求通知权限。 对每笔有效定期存款，Maturity 会安排两次提醒：到期日前七天上午 9:00 一次，到期当天上午 9:00 再一次。 通知会显示银行和日期，但不会显示金额。

提醒仅保存在本机，因此请在每台需要接收提醒的设备上分别启用。如果权限被阻止，请在“系统设置”中允许 Maturity 发送通知，然后返回应用开启提醒。关闭到期提醒会从该设备移除由 Maturity 管理的通知。

如何更改应用语言？

打开设置并选择语言。保留系统默认即可跟随设备语言， 或选择英语、德语、西班牙语、法语、意大利语、日语、韩语、葡萄牙语（葡萄牙）、简体中文、繁体中文或 繁体中文（香港）。界面会立即切换。

你的选择只应用于当前设备，不会更改或翻译已输入的财务记录。其他设备会保留各自的语言选择。

可以重新排列账户，或按银行将账户分组吗？

两者都可以，而且分组会自动进行。在每个账户上记录银行，Maturity 就会在账户出现的所有位置 按银行分组——包括设置、“现金存放位置”和每个账户下拉菜单。同一家金融机构的账户始终相邻，无论第二个账户多晚添加， 因此你无需在很长的列表中寻找同一家银行的另一个账户。

新账户也会直接插入同一家银行的其他账户之后，而不是添加到列表末尾，因此保存顺序与你看到的顺序一致。 添加账户时，银行字段会提供你已经记录的金融机构选项，避免同一家银行因不同拼写而变成三组。

如需手动排序，请在设置中打开账户菜单，选择上移或下移以调整它在同一家银行内的顺序； 也可选择将<银行>上移／下移来移动整家银行。银行标题旁的箭头执行相同操作。所有列表共用一套顺序， 因此在设置中指定的排列也会出现在下拉菜单中。未记录银行的账户会集中在末尾的独立标题下。

我的账户之间转账时如何记录？

你需要输入两个金额：从一个账户转出的金额，以及另一个账户实际收到的金额。 它们是来自两份不同对账单的两个独立事实，而到账金额才真正决定你能在目标账户使用多少资金。 同币种转账时，第二个金额默认与第一个相同；如果实际到账金额不同，仍可编辑。

由于转出和到账两端都按实际发生情况记录，跨币种转账无需使用汇率。输入转出的美元和到账的欧元， 每个余额都能保持准确。转账不会改变你的总体持有金额，只会改变资金所在位置，因此不会被视为支出和收入。 删除其中一端会同时删除两端，因为只留半笔转账会让资金看起来凭空消失。

可以追踪多种货币的定期存款吗？

可以。在设置中添加你使用的货币，并选择一种作为默认货币。每笔定期存款和现金变动都以一种货币计价， 每个金额都以该货币的原始单位显示。

当前可用资金、本金、加权平均收益率和到期阶梯都会按货币分别报告。准确的原始货币数字才是权威数据； 不同货币绝不会直接相加。核对也按账户和货币分别进行，与核对银行对账单的方式一致。

既然不同货币不会相加，如何进行比较？

摘要会用各自的原始单位列出每种货币的追踪持仓。货币行超过三行时会折叠，以保持标题区域简洁； 使用显示全部和收起即可展开或折叠。

下方的比较使用不带货币单位的指标：加权平均利率、闲置现金占比和平均剩余期限天数。 条形图表示的是比率，绝不会把不同货币的余额绘制在同一坐标轴上。应用也会明确指出：考虑到汇率变动， 一种货币的利率更高并不一定意味着换成另一种货币后回报更好。

可以查看所有货币合并后的一个总额吗？

可以，但它只是估算值，而且只有在你主动要求时才会显示。在设置中开启显示参考等值。 摘要随后可能显示完整追踪持仓的一项次要“≈”等值金额，并注明日期和参考汇率来源。

只有在每一种有追踪持仓的货币都能换算时，它才会出现。如果缺少任何所需汇率，就不会显示不完整的部分数值。 应用不会另外显示换算后的当前可用资金总额或本金总额。以原始货币记录的数字始终是权威数据，且绝不会直接相加。

换算结果不会被存储，不会应用于任何余额，也不会用于收益率或利息数字——汇率变化不会改变你的记录。 汇率是从 Frankfurter 获取的每日公开参考汇率。实际转账结果会有所不同，因为这里不包含银行的汇率和费用。

只有启用此功能，应用才会联系你自己的 iCloud 以外的服务。请求只包含货币代码，不包含持仓金额、名称或记录标识符； 完整网络披露请参阅隐私政策（英文）。再次关闭该功能会删除缓存的汇率。

流动性时段包含哪些日期？

每个截止日期都包含边界当天。今天包括恰好 0 天，1 周包括恰好 7 天。 1 个月截至从今天起向后一个日历月的日期，3 个月截至向后三个日历月的日期； 这里按日历加月计算，不是固定的 30 天或 90 天跨度。

如果我设置两次期初余额，会发生什么？

第二次会替换第一次，而不是累加。每个账户只有一个期初余额，也就是账户历史的起点， 因此表单会说明已记录的内容，按钮也会显示替换余额。

这一点很重要，因为当前可用资金是整个交易历史的总和，而不是一个单独保存的数字。如果一个账户有两个期初余额， 同一笔资金就会被悄悄计算两次，界面上却没有任何提示。如果要记录开始追踪之后到账的资金，请改用 现金流入——那是一次变动，而不是起点。

可以更改到期阶梯的分组方式吗？

可以。到期阶梯可按月或季度分组。默认使用季度，因为它更紧凑： 如果稀疏的阶梯显示为十二个月度列，一根柱形周围大部分都会是空白。你的选择会在下次启动时保留。

每个期间只显示一个堆叠柱形，本金和利息位于同一柱形中，因此柱形高度就是该期间的总额， 同时也能看到两部分的划分。将指针移到任一期间，即可查看准确的本金、利息及付款金融机构。

为什么我的货币符号中包含字母？

设备的地区设置会影响货币符号的显示方式。为避免符号产生歧义，系统可能添加字母——例如显示 US$ 或 HK$， 而不是只显示 $——以区分不同货币。如果希望在系统支持的情况下显示纯符号，请将设备地区设为与你的主要货币一致。

利息如何计算？

Maturity 默认使用实际天数/365 作为计息天数基准。每笔定期存款也可选择实际天数/360 和 30/360， 以匹配产品注明的惯例。每个计息期间结束时，利息会四舍五入到最接近的分，这也符合银行的做法； 因此，定期支付利息的存款，其总利息可能与按完整期限一次计算的结果相差一两分。

应用计算的数字与银行不一致，应该以哪个为准？

以银行数字为准。正因如此，Maturity 中的每个计算结果都可以编辑——请查找使用银行报价金额的选项。 小额差异的常见原因包括采用了不同的计息天数基准、从存款次日而不是当天开始计息，或银行在不同步骤进行舍入。 输入实际数字后，应用就会记录该数字。

提前支取定期存款时如何处理？

各金融机构的条款不同。有些会减少利息，和／或要求在释放资金前提前通知。Maturity 会将通知和结算记录为两个独立阶段， 使这段间隔内的现金预测保持准确，并估算减少后的利息。金融机构的报价才是权威依据，因此取得报价后请录入该数字。

定期存款续存时会发生什么？

请使用续存，而不是先收回资金再重新存入。它会结束旧存款、开立新存款并记录两端， 因此历史会显示资金从未经过日常账户。你可以只续存部分所得并将其余部分保留为现金；如果你想把利息作为收入取出、 只再投资本金，这种做法很常见。新利率会有意留空：银行采用的是续存日的现行利率，而不是原来的利率。

为什么应用要求我确认利息付款？

对于按月或按季度支付利息的定期存款，应用知道付款何时到期，但不会自行写入你的账本。 将未经确认的数字放入历史记录会妨碍核对，并留下你从未检查过的数据。因此，应用会在摘要屏幕提示你， 你可以点按一次接受，也可以先修改金额。

我的设备没有同步。

请确认两台设备登录了同一个 Apple 账户、已开启 iCloud 云盘，并且在 iCloud 设置中启用了 Maturity。 同步需要网络连接，而且可能需要一点时间才能完成。通常，在两台设备上都将应用切换到前台即可促使数据交换。 如果设备根本没有登录 iCloud 账户，应用仍可运行，并会将数据保存在本地。

我的数据有备份吗？

如果已开启 iCloud 同步，你的记录会同时存在于私密 iCloud 容器和每台设备上，因此丢失一台设备不会导致数据丢失。 但这不能替代经过审慎考虑的备份策略。开发者没有你的应用内持仓组合副本，无法代为恢复。你主动通过 GitHub 提交的 支持内容与此分开，开发者和公众可能都能看到这些内容。

应用可以自动连接我的银行吗？

不可以，这是有意的设计。Maturity 从不要求银行登录凭据，也不会联系任何金融机构。 所有内容都由手动输入，因此没有可能泄露的凭据，也没有第三方介于你和银行之间。

删除定期存款会改变我的现金余额吗？

默认不会。删除定期存款时，其现金变动会保留在账本中，因此自由现金不受影响——删除一条记录不应悄悄改写现金历史。 如果你是在清理由于误操作而输入的内容，请选择同时删除定期存款及其历史记录的选项。

报告计算问题

利息计算尤其需要准确，因此特别欢迎此类问题报告。请提供：

  • 本金、利率、起始日期和到期日期
  • 利息支付频率和所选计息天数基准
  • 应用显示的数字，以及银行提供的数字

不构成财务建议

Maturity 是一款记录和计算工具。它不提供财务、投资或税务建议，也不推荐产品或金融机构。 任何重大事项请与你的金融机构或持牌顾问确认。
