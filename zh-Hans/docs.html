导出你的 Maturity 数据

Schema v1 · 本地 JSON 和 CSV 导出

一切由你掌控。Maturity 只会在你主动要求时创建导出文件。 应用会把生成的文件交给系统保存面板或共享表单；它不会上传文件、选择接收者， 也不会把文件发送给开发者。

1. 创建导出文件

在 Maturity 中，打开设置 → 数据 → 导出投资组合…。选择格式和隐私模式， 阅读应用中显示的说明，然后点按导出。

在 Mac 上，请在系统保存面板中选择目标位置。在 iPhone 和 iPad 上，请从系统共享表单中 选择目标位置或接收者。选择其他应用、服务或人员后发生的操作不受 Maturity 控制。

2. 选择隐私模式

  • 已隐去敏感信息是默认选项。金融机构和账户名称会替换为该次导出专用的别名，并排除用户输入的自由文本。
  • 财务分析会将金融机构名称替换为别名，并排除参考信息、备注和交易附言；账户名称会保留。
  • 完成会包含金融机构和账户名称、参考信息、备注及交易附言。

“财务分析”和“已隐去敏感信息”导出经过假名化处理，并非匿名化。 为准确表示持仓组合，所有模式都会保留金额、利率、日期、货币、状态及关系标识符。 这些字段可能使导出内容与其他信息关联起来。共享前请检查实际生成的文件；除非确实需要 可读标签，否则应优先选择“已隐去敏感信息”。

3. JSON 快照

JSON 选项会创建带版本、可供机器读取的快照。文件包含持仓组合记录，以及预先计算的摘要、 现金流、到期期间、流动性行、需留意事项和导出来源信息。各货币的数值始终分开；导出不会 为不同货币虚构一个合计总额。

文件中的 schema 信息可让兼容软件识别其格式。即使选择“已隐去敏感信息”模式，也应将完整的 JSON 对象视为敏感财务信息。

4. CSV 数据包

CSV 选项会创建一个 .maturitycsv 文档包，其中包含一个 manifest.json 文件和多个可相互关联的独立 CSV 表格。相关记录会分别保存在 不同表格中，而不是被压平成一个含义不清的电子表格。

在 Mac 上，你可以在访达中选择显示包内容来检查这个文档包。 电子表格应用可能会按照自身方式格式化日期、标识符、利率或大数值，因此任何重要内容都应 与 Maturity 及金融机构记录进行核对。

5. 安全共享导出文件

Maturity 不会自动传输导出文件。如果你将文件提供给云存储、AI 助手、分析软件、财务顾问 或其他人员，接收方会取得该文件，并可能按照其自身条款传输、处理、保留或记录其中内容。 这种由用户主动发起的共享不会让 Maturity 的开发者获得导出文件。

  • 除非接收方确实需要可读名称或备注，否则请使用“已隐去敏感信息”模式。
  • 共享前请打开并检查最终生成的文件。
  • 只发送给你信任的接收者和服务。
  • 请使用目标位置提供的控制功能来存储和删除导出副本。
  • 不要在公开的 GitHub issue 或其他公开支持渠道中发布导出文件。

关于保留字段、本地导出处理方式和第三方目标位置的完整说明，请参阅 隐私政策（英文）。

6. 导出不会执行的操作

  • 它不会连接银行、向金融机构核实记录，也不会转移资金。
  • 它不会自行上传，也不会暴露 Maturity 的实时 SwiftData 存储或私密 iCloud 容器。
  • 它不会使“财务分析”或“已隐去敏感信息”数据变为匿名数据。
  • 它不会让计算结果的权威性高于银行对账单或报价。

不构成财务建议

Maturity 是一款记录和计算工具。它不提供财务、投资或税务建议，也不推荐产品或金融机构。 导出数据取决于用户提供的记录；银行对账单和报价仍为权威依据。任何重大事项请与你的 金融机构或持牌顾问确认。
