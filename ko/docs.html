Maturity 데이터 내보내기

Schema v1 · 로컬 JSON 및 CSV 내보내기

사용자가 계속 통제합니다. Maturity는 사용자가 요청할 때만 내보내기 파일을 만듭니다. 앱은 완성된 파일을 시스템 저장 패널 또는 공유 시트로 전달할 뿐, 파일을 업로드하거나 수신자를 선택하거나 개발자에게 보내지 않습니다.

1. 내보내기 만들기

Maturity에서 설정 → 데이터 → 포트폴리오 내보내기…를 여세요. 형식과 개인정보 보호 모드를 선택하고 앱에 표시되는 설명을 검토한 다음 내보내기를 누르세요.

Mac에서는 시스템 저장 패널에서 저장 위치를 선택합니다. iPhone과 iPad에서는 시스템 공유 시트에서 저장 위치 또는 수신자를 선택합니다. 다른 앱, 서비스 또는 사람을 선택한 뒤의 과정은 Maturity가 통제하지 않습니다.

2. 개인정보 보호 모드 선택하기

  • 가림 처리됨이 기본값입니다. 금융기관 및 계좌 이름은 내보내기별 별칭으로 바뀌고 사용자가 입력한 자유 형식 텍스트는 제외됩니다.
  • 재무 분석은 금융기관 이름을 별칭으로 바꾸고 참조, 참고 사항과 메모를 제외하지만 계좌 이름은 유지합니다.
  • 완료는 금융기관 및 계좌 이름, 참조, 참고 사항과 거래 메모를 포함합니다.

재무 분석 및 가림 처리됨 내보내기는 가명 처리된 것이며 익명화된 것이 아닙니다. 모든 모드에는 포트폴리오를 정확하게 나타내는 데 필요한 금액, 금리, 날짜, 통화, 상태와 관계 식별자가 유지됩니다. 이러한 필드 때문에 내보내기를 다른 정보와 연결할 수 있습니다. 공유하기 전에 실제 결과물을 검토하고, 읽을 수 있는 레이블이 꼭 필요하지 않다면 가림 처리됨를 사용하세요.

3. JSON 스냅샷

JSON 옵션은 버전이 지정된 기계 판독 가능 스냅샷을 만듭니다. 포트폴리오 기록과 함께 미리 계산된 요약, 현금 흐름, 만기 기간, 유동성 행, 주의가 필요한 항목과 내보내기 출처 정보가 포함됩니다. 값은 통화별로 계속 구분되며, 내보내기가 서로 다른 통화를 합친 총액을 임의로 만들지 않습니다.

파일의 스키마 정보를 통해 호환 소프트웨어가 형식을 식별할 수 있습니다. 가림 처리됨 모드를 선택했더라도 전체 JSON 객체를 민감한 금융 정보로 취급하세요.

4. CSV 데이터 패키지

CSV 옵션은 manifest.json 파일과 서로 연결할 수 있는 별도의 CSV 표가 들어 있는 .maturitycsv 문서 패키지를 만듭니다. 포트폴리오를 의미가 불분명한 하나의 스프레드시트로 평면화하지 않고 관련 기록을 별도 표로 구분해 유지합니다.

Mac에서는 Finder에서 패키지 내용 보기를 선택해 패키지를 살펴볼 수 있습니다. 스프레드시트 앱은 날짜, 식별자, 금리 또는 큰 숫자를 자체 방식으로 표시할 수 있으므로 중요한 내용은 Maturity 및 금융기관의 기록과 비교하세요.

5. 내보내기 안전하게 공유하기

Maturity는 내보내기 파일을 자동으로 전송하지 않습니다. 클라우드 저장 공간, AI 도우미, 분석 소프트웨어, 재무 자문가 또는 다른 사람에게 파일을 전달하면 해당 수신자가 결과물을 받으며, 자체 약관에 따라 이를 전송, 처리, 보관 또는 기록할 수 있습니다. 사용자가 직접 시작한 이러한 공유로 Maturity 개발자가 내보내기에 접근할 수 있게 되는 것은 아닙니다.

  • 수신자에게 읽을 수 있는 이름이나 참고 사항이 꼭 필요하지 않다면 가림 처리됨 모드를 사용하세요.
  • 공유하기 전에 완성된 결과물을 열어 검토하세요.
  • 신뢰하는 수신자와 서비스에만 보내세요.
  • 내보낸 사본은 저장 대상에서 제공하는 기능을 사용해 보관하고 삭제하세요.
  • 공개 GitHub 이슈나 그 밖의 공개 지원 채널에 내보내기 파일을 게시하지 마세요.

유지되는 필드, 로컬 내보내기 처리와 제3자 전송 대상에 관한 전체 설명은 개인정보 처리방침(영어)을 참조하세요.

6. 내보내기가 하지 않는 일

  • 은행에 연결하거나, 금융기관을 통해 기록을 검증하거나, 돈을 이동하지 않습니다.
  • 스스로 업로드되거나 Maturity의 실제 SwiftData 저장소 또는 비공개 iCloud 컨테이너를 노출하지 않습니다.
  • 재무 분석 또는 가림 처리됨 데이터를 익명으로 만들지 않습니다.
  • 계산된 수치를 은행 명세서나 제시 금액보다 더 권위 있는 정보로 만들지 않습니다.

금융 자문이 아닙니다

Maturity는 기록 관리 및 계산 도구입니다. 금융, 투자 또는 세무 자문을 제공하지 않으며 상품이나 금융기관을 추천하지 않습니다. 내보낸 수치는 사용자가 제공한 기록을 바탕으로 하며, 은행 명세서와 제시 금액이 기준입니다. 중요한 사항은 해당 금융기관 또는 면허를 보유한 자문가와 확인하세요.
